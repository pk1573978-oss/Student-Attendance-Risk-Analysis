# Student Attendance Risk Analysis Dashboard
This Power BI project analyzes student attendance data to identify students at different attendance risk levels. The dashboard helps visualize attendance trends across departments and academic years using interactive reports.
## Objectives
- Analyze student attendance patterns
- Identify High, Moderate, and Low Risk students
- Compare attendance across departments
- Evaluate attendance by academic year
- Provide interactive filtering using slicers
## Dataset
The dataset includes:
- Student ID
- Student Name
- Department
- Academic Year
- Subject
- Attendance Percentage
- Classes Attended
- Total Classes
- Risk Level
## Dashboard Features
### Dashboard 1
-Total Student Count
 - Year Filter
- Risk Level Distribution
- Department-wise Attendance Analysis
### Dashboard 2
- Department-wise Total Classes
- Average Attendance by Risk Level
- Subject-wise Risk Distribution
- Interactive Navigation Buttons
