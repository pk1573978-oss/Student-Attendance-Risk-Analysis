# 🎓 Student Attendance Risk Analysis Dashboard

## 📖 Project Overview

This Power BI project analyzes student attendance data to identify attendance risk levels across departments and academic years. The dashboard enables users to explore attendance trends using interactive filters and visual reports.

---

## 🎯 Objectives

- Analyze student attendance patterns
- Identify High, Moderate, and Low Risk students
- Compare attendance across departments
- Evaluate attendance by academic year
- Build interactive reports using slicers and navigation buttons

---

## 📂 Dataset

The dataset contains the following fields:

- Student ID
- Student Name
- Department
- Year
- Subject
- Attendance Percentage
- Classes Attended
- Total Classes
- Risk Level

---

## 📊 Dashboard Features

### Dashboard 1

- Total Student Count KPI
- Year Filter (Slicer)
- Risk Level Distribution
- Department-wise Average Attendance Analysis

### Dashboard 2

- Department-wise Total Classes
- Average Attendance by Risk Level
- Subject-wise Risk Distribution
- Interactive Navigation Buttons
